# Toolmim · 图明 AI 全能箱实现计划

项目从 Pi Agent 任务书实现本地优先工具箱。使用 React/TypeScript/Vite、Fastify 本地服务和真实 Pi SDK。只监听回环地址，数据留在 `.data/`；不增加商用、账户体系、计费或桌面封装。

1. 核对官方文档和已安装资源，锁定可执行入口与限制。
2. 首页、四个专用输入页面、任务中心、Agent、Skills 与设置共用共享类型和 API。
3. Pi SDK 负责模型步骤、真实事件、资源发现和会话文件；本地任务管理器负责队列、人工确认、取消、重试、重启中断识别。
4. 已验证 CLI 用独立进程和参数数组执行；模型与账户缺失显示诊断，不用模拟结果。
5. 验证输入、目录、敏感日志、取消和持久化；运行单元/集成、浏览器和真实非破坏性技能调用。

影响范围：前端调用、共享 Schema、后端 API、Pi 运行时、四个适配器、素材与产物接口、任务持久化、测试、启动脚本与 README。凭据只经服务器保管；发布走预览与人工确认；不修改外部独立项目。
